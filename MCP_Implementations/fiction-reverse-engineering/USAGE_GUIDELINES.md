# Fiction Reverse Engineering MCP — Usage Guidelines

## Use this MCP when

1. **Learning** — studying bestsellers to understand pacing, tension, and dialogue patterns
2. **Diagnosis** — something feels off and you want objective metrics
3. **Revision** — polishing after the creative draft
4. **QA** — final quality check before publication

## Do not use this MCP when

1. **Creative drafting** — formulas kill flow
2. **Every decision** — over-reliance creates formulaic prose
3. **Copying bestsellers** — derivative work
4. **Replacing your voice** — craft supports voice; it does not replace it

## Tools

| Tool | Purpose |
|------|---------|
| `reverse_engineer_novel` | Extract and save a structural formula |
| `compare_to_bestseller` | Compare your text to a saved formula |
| `analyze_pacing` | Tension / reveal / dialogue metrics |
| `extract_dialogue_formula` | Dialogue tags, beats, exchange lengths |
| `find_chapter_formula` | Chapter hooks and act-tension thirds |
| `list_available_formulas` | List saved formulas |

Every tool response includes a learning-tool warning. Treat metrics as guides, not rules.
