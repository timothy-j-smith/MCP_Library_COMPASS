# MCP Setup Index

This folder contains MCP setup and configuration guidance for this workspace template.

## Canonical Setup Sequence

1. **Start here for Slack + multi-repo MCP scope:** `GLOBAL_MCP_AND_SLACK_CONNECTION_MAP.md` — put Slack (and other shared MCPs) in `~/.cursor/mcp.json` so they work in every Cursor repo, not only this one.
2. Review `MCP_SETUP_INSTRUCTIONS.md` for baseline setup flow.
3. Use `MCP_API_KEYS_AND_SETUP_REFERENCE.md` for credential and server reference details.
4. Use `CURRENT_STATE.md` for the living “what’s active + global vs project” table.
5. Use `MCP_SETUP_SUMMARY.md` for the latest consolidated snapshot.

## Historical Snapshots

Some files in this folder are date-stamped completion snapshots (for example `*_COMPLETE*` and `*_GUIDE*`).  
Treat those as historical context unless they are explicitly updated as current.

## Professional Standard

- Keep one actively maintained "current state" document.
- Mark superseded setup snapshots clearly.
- Prefer reproducible instructions and explicit verification steps.
