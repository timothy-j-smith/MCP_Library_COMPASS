## What Is This Folder?

This is your central library -- shared across all novel workspaces via Multi-Root Workspaces. It contains:

- **MCP Encyclopedia** -- The master reference for all 66+ MCPs
- **MCP Research** -- Deep dive analysis and evaluation documents
- **MCP Setup** -- Installation guides, API references, status files
- **Sequential Thinking** -- The Brothers' documentation and applications
- **COMPASS** -- The complete COMPASS Writing System (agents, commands, prompts)
- **Cursor Guides** -- Mastery guides for Cursor features
- **Git Guides** -- Git, GitHub, and GitKraken documentation
- **Automation** -- Quick Wins, workflows, and toolbox orchestration
- **Style MCPs** -- Dennis Lehane style, Fiction Reverse Engineering, etc.
- **Session Analysis** -- Past session analysis and chat transcript reviews

## How to Use

This folder appears in any novel workspace's sidebar when you open the novel's `.code-workspace` file. For example, opening `Walk_This_Way.code-workspace` shows both your novel AND this library side by side.

## This Is a Git Repository

This folder has its own Git repo, separate from any novel. Push to GitHub to sync between Mac Studio and MacBook Air.
