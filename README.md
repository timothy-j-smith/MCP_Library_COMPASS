# Cursor 3 Workspace Template

Professional, documentation-first workspace template for advanced Cursor usage with agent workflows, MCP orchestration, and structured analysis artifacts.

## Template Goal

This repository is designed to be a reusable, high-signal workspace for:
- Cursor 3 agent-first development workflows
- Built-in tools usage (Agent, Ask, TODOs, terminal, context references)
- MCP research, setup, and operations
- Sequential Thinking "brothers" style multi-perspective analysis

## Start Here

1. Read `Cursor_Guides/CURSOR_3_TOOLS_AND_AGENTS_GUIDE.md`.
2. Read `.cursor/README.md` to understand project rules, commands, and hooks.
3. Use `Cursor_Guides/README.md` to navigate all Cursor-focused guides.
4. Use `Sequential_Thinking/README.md` to navigate the "brothers" analysis set.

## Cursor 3 Coverage Checklist

- Agent workflows (edit-capable execution)
- Ask workflows (analysis and planning without edits)
- Background-agent orientation and expectations
- Built-in tool usage guidance (terminal, TODOs, context references)
- MCP workflow references and setup documentation
- `.cursor` project-level rules, command helpers, and request guidance

## Repository Map

- `Cursor_Guides/` - Cursor operation guides, including Cursor 3 workflows
- `.cursor/` - Project-scoped Cursor rules, commands, and automation hooks
- `Sequential_Thinking/` - "Brothers" multi-perspective analysis playbooks
- `MCP_Setup/` - MCP installation and setup instructions
- `MCP_Research/` - MCP evaluations and research reports
- `Automation/` - Workflow automation analyses and templates
- `Style_MCPs/` - Style/emulation-oriented MCP docs
- `Git_Guides/` - Git and GitHub workflow references
- `COMPASS_Docs/` - COMPASS architecture and roadmap docs

## Professional Usage Notes

- Treat `Cursor_Guides/CURSOR_3_TOOLS_AND_AGENTS_GUIDE.md` as the current operational reference.
- Treat older "completion" and "status snapshot" docs as historical context unless explicitly updated.
- Prefer reproducible workflows (documented commands, explicit file references, and scoped changes).

## Maintenance Standard

When adding new material:
- Add or update an index/README in the affected folder.
- Mark superseded guidance clearly instead of silently replacing it.
- Keep Cursor-facing guidance aligned with current product behavior and naming.
