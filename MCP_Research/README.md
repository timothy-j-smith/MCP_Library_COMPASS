# MCP Research Index

This directory contains research and evaluation documents for MCP tools and strategy.

## Purpose

Use this folder for comparative analysis, option screening, and rationale capture.  
Treat date-stamped "final" or "complete" docs as snapshots unless explicitly marked current.

## Recommended Reading Order

1. `MCP_RESEARCH_SUMMARY.md` for broad orientation.
2. `MCP_FINAL_RESEARCH_REPORT.md` for comprehensive analysis.
3. Topic-specific files (`MCP_*_ANALYSIS.md`, `MCP_*_EVALUATION.md`) for deep dives.

## Professional Usage Standard

- Keep one clearly identified current summary and link older snapshots as historical.
- Prefer decision criteria and tradeoff reasoning over tool hype.
- Cross-link setup instructions in `MCP_Setup/` when recommendations require implementation steps.
